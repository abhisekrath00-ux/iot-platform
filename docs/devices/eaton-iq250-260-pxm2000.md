## Link

Modbus RTU on the RS-485 port; the same holding-register map applies over Modbus TCP on units
with the Ethernet option. Holding registers only (the doc's B-3 note), so reads use FC 03.
Serial parameters are programmed on the meter (programmable settings): baud 9600-57600,
parity none/even/odd, 1 or 2 stop bits. Match the Edge setup form to the meter's settings.

## Addressing and value format (all vendor-stated)

- The map's HEX column is the wire (PDU) address. The doc's own example: serial number is hex
  0008-000F = decimal 9-16; SCADA UIs enter 40009; drivers strip the leading 4 and subtract 1,
  landing on address 8 = hex 0008.
- FLOAT: 32-bit IEEE-754 over 2 registers, the lower-addressed register is the high-order half
  (contains the exponent) - big-endian, ABCD. The B-2 worked example (registers C4E1 1DB9 =
  -1800.929) also proves a signed float is well-defined, so negative power/PF readings are fine.
- SINT32/UINT32: 32-bit signed/unsigned over 2 registers, lower-addressed register is the
  high-order half. Signedness is documented, so the energy counters are used as SINT32.

## Measurements (read-only, FC 03, hex = wire address, FLOAT)

| Point | Address | Unit |
|---|---|---|
| va_n, vb_n, vc_n | 0x03E7, 0x03E9, 0x03EB | V (L-N) |
| va_b, vb_c, vc_a | 0x03ED, 0x03EF, 0x03F1 | V (L-L) |
| ia, ib, ic | 0x03F3, 0x03F5, 0x03F7 | A |
| p_total, q_total, s_total | 0x03F9, 0x03FB, 0x03FD | W / var / VA |
| pf_total | 0x03FF | -1.00 to +1.00 |
| freq | 0x0401 | Hz (doc range 0-65) |
| i_n | 0x0403 | A (neutral current) |
| p_a, p_b, p_c | 0x0405, 0x0407, 0x0409 | W |
| q_a, q_b, q_c | 0x040B, 0x040D, 0x040F | var |
| s_a, s_b, s_c | 0x0411, 0x0413, 0x0415 | VA |
| pf_a, pf_b, pf_c | 0x0417, 0x0419, 0x041B | -1.00 to +1.00 |

Doc note 2: per-phase power and PF have values only for WYE hookup and are zero for all other
hookups.

## Energies (read-only, FC 03, SINT32, Primary Energy Block)

| Point | Address | Unit |
|---|---|---|
| energy_received | 0x05DB | Wh |
| energy_delivered | 0x05DD | Wh |
| energy_net | 0x05DF | Wh |
| energy_total | 0x05E1 | Wh |
| varh_positive | 0x05E3 | varh |
| varh_negative | 0x05E5 | varh |
| varh_net | 0x05E7 | varh |
| varh_total | 0x05E9 | varh |
| vah_total | 0x05EB | VAh |

Energy caveat: the units column says "Wh per energy format" - the implied decimal point and the
unit scale (units/kilo/mega) follow the meter's programmed Energy Format setting (5 to 8 digits,
decimal point implied). The template reads these counters raw (scale 1); the operator must know
the meter's configured energy format to interpret the magnitude. Received/delivered always have
opposite signs; which one is positive depends on the "view as load"/"view as generator" setting
(doc comments).

## Excluded

The integer Readings Block (registers 279-305: values scaled by programmable settings flags),
demand block, phase-angle block, status block, THD block, min/max blocks, accumulators, the
secondary readings section (40001-40100), log retrieval, and the entire commands and programmable
settings sections (writes) - the template is read-only.
